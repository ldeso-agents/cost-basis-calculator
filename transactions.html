Transaction CSV Export

Download every transaction touching an address on Ethereum, Polygon, Base, Optimism, or Arbitrum between two dates as a CSV file. Everything runs in your browser — the Alchemy API key is used directly from this page and never sent anywhere else. Want the balances rather than the activity? Portfolio rewind reconstructs everything an address held on a given date.

What is this?

This page exports the full on-chain activity of a single address in a given time window: native-currency transfers (external and, where the network supports it, internal), ERC-20, ERC-721, and ERC-1155 token transfers, both incoming and outgoing. The result downloads as a CSV you can open in any spreadsheet or feed into other tooling.

How it works

  • The from/to times (interpreted as UTC) are resolved to an exact block range by binary-searching block timestamps over the RPC endpoint (https://<network>.g.alchemy.com/v2/<ALCHEMY_API_KEY>). Leave either blank for an open-ended window.
  • Two paginated alchemy_getAssetTransfers queries (one for toAddress, one for fromAddress) pull every transfer in the block range across all categories the selected network supports.
  • Rows are de-duplicated (a self-transfer is reported once, with direction self), ERC-1155 batch transfers are expanded to one row per token id, and everything is sorted by block number.

CSV columns

timestamp_utc, block_number, tx_hash, direction (in / out / self), from, to, category (external, internal, erc20, erc721, erc1155, specialnft), asset (symbol), amount (decimal-adjusted), raw_value (unadjusted hex amount, useful when Alchemy does not know a token’s decimals and amount is empty), contract_address, token_id, unique_id (Alchemy's stable transfer identifier).

Notes & limitations

  • An Alchemy API key is required because alchemy_getAssetTransfers is a custom Alchemy method.
  • One transaction can produce several rows (e.g. a swap emits an outgoing and an incoming token transfer); tx_hash groups them.
  • Amounts are the decimal-adjusted values reported by Alchemy; gas costs are not included as separate rows.
  • Categories not supported by the selected network (e.g. internal on some chains) are skipped automatically.
